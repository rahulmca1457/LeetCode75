# ZYRORA AI Hackathon - Plant Disease Project Blueprint

### STEP 1: GET YOUR KAGGLE KEY (On Your Computer)
1. Go to Kaggle.com, click your profile picture, and go to "Settings".
2. Scroll down to the API section and click "Create New Token".
3. A tiny file named `kaggle.json` will download. Keep it safe on your laptop.

### STEP 2: TRAIN THE MODEL (In Google Colab)
1. Open a new Google Colab notebook.
2. Switch runtime to GPU: Click Menu -> Runtime -> Change runtime type -> Select "T4 GPU" -> Save.
3. Open the built-in Gemini AI panel on the right side of Colab.
4. Use Gemini to write and run the code for these 4 tasks sequentially:
   - Task A: Upload `kaggle.json` and download the dataset ("vipoooool/new-plant-diseases-dataset").
   - Task B: Load images using `tf.keras.utils.image_dataset_from_directory` resized to 224x224.
   - Task C: Build a MobileNetV2 Transfer Learning model (weights='imagenet') with a 38-class Softmax layer.
   - Task D: Train for 5 epochs, save as `plant_disease_model.keras`, and download it to your laptop.

### STEP 3: UPLOAD MODEL TO CLOUD (On Hugging Face)
1. Go to HuggingFace.co and create a free account.
2. Click "New" -> "Model" to create a public repository. Name it `plant-disease-model`.
3. Click the "Files and versions" tab and upload your `plant_disease_model.keras` file.
4. Once uploaded, click on the file name, right-click the "download" button, and click "Copy Link Address". This is your direct model download URL.

### STEP 4: SETUP CODE REPOSITORY (On Your Computer & GitHub)
1. Create a new folder on your laptop. Inside it, create exactly three files:
   - `app.py`: Your Flask API script. Paste your Hugging Face direct download link inside the `MODEL_URL` variable.
   - `requirements.txt`: Paste these lines:
     flask
     flask-cors
     tensorflow-cpu
     pillow
     numpy
     gunicorn
   - `render.yaml`: Paste these lines:
     services:
       - type: web
         name: zyrora-plant-api
         env: python
         buildCommand: pip install -r requirements.txt
         startCommand: gunicorn app:app --workers=1 --threads=2 --backlog=50
2. Create a new public repository on GitHub.com and upload these 3 files into it.

### STEP 5: GO LIVE (On Render)
1. Go to Render.com and create a free account.
2. Click the "New +" button and select "Web Service".
3. Connect your GitHub account and choose your plant disease project repository.
4. Click "Deploy". Render automatically reads your `render.yaml` file, installs the packages, pulls your model from Hugging Face into memory, and gives you a live API web link!
